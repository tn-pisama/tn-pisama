# Hi, I’m Tuomo. I build Pisama.

My work focuses on finding where AI agent workflows go wrong—and verifying whether a proposed fix actually resolves the failure.

At [Pisama](https://pisama.ai), I’m building adaptive failure detection, evidence-backed fix recommendations, and a feedback loop that turns verified fixes into improvements to agent instructions.

[Website](https://pisama.ai) · [Documentation](https://docs.pisama.ai) · [Pisama on GitHub](https://github.com/Pisama-AI)

## Selected work

- [pisama-python](https://github.com/Pisama-AI/pisama-python) — Python CLI, SDK, and MCP server.
- [pisama-js](https://github.com/Pisama-AI/pisama-js) — TypeScript SDK, detectors, and CLI.
- [pisama-n8n](https://github.com/Pisama-AI/pisama-n8n) — Failure detection for n8n workflows.
- [pisama-verifier-gym](https://github.com/Pisama-AI/pisama-verifier-gym) — Verifier audits, agreement metrics, and release gates; used internally, with limited external maintenance.
